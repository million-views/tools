# Changelog

Notable user-facing features and compatibility changes.

## [0.2.0] - 2026-11-10

- Save panes with unknown folders and identify them in list and restore views.
- Read format-1 snapshots and format-2 snapshots with nullable pane folders.

## [0.1.0] - 2026-11-10

- Save and inspect Ghostty windows, tabs, folders and Claude Code, Codex and pi
  sessions.
- Restore selected sessions into Ghostty with duplicate warnings, an interactive
  picker and recovery of plain shell tabs.
- Check installation, permissions and saved session state with `tsr doctor`.
- Read and preserve format-1 snapshots.
